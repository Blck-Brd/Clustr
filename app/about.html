Sort thousands of camera photos into trips, stops and events.

Clustr is a browser-based photo organizer for real camera libraries. It reads EXIF, matches photo times against Google Timeline, finds trips and stops with density heatmaps, and exports a clean folder tree with Adobe Lightroom XMP sidecars.

How Clustr works

Five phases, each optional except the ones you need, with settings kept behind a cog.

  1. Upload the camera folder. Select JPG, HEIC or RAW files from a directory on your PC.
  2. Add Google Timeline (optional). Import a Timeline JSON export so locations can be assigned by photo time.
  3. Extract EXIF and cluster. Auto clustering builds trip and stop folders from density; heatmap mode lets you draw ranges manually.
  4. Name and enrich (optional). Use Ollama or Gemini for event names, and a local vision model for tags.
  5. Review and export. Filter, rename, triage with Tinder mode, then write folders and XMP sidecars.

Built for a PC + camera workflow

Clustr assumes your photos are copied from a camera or memory card to a computer, then sorted and exported there in a Chromium-based desktop browser. That is where folder import, direct disk export and local AI work best.

  • Windows-safe folder and file names
  • RAW and HEIC previews from embedded thumbnails or paired JPGs
  • Duplicate-safe import and a virtualized gallery for large libraries
  • Optional local Ollama models, or Gemini for cloud naming

Phone use is secondary, but real

The same app installs as a PWA. On a phone you can add photos from the camera roll, run the phases, browse the folder tree, draw touch ranges on the heatmap, use Tinder review and export a ZIP with XMP sidecars.

  • Camera-roll import with duplicate skipping
  • Touch-friendly full-screen heatmap
  • ZIP export with Web Share or save-to-Files
  • Gemini naming; Ollama stays desktop-only

Frequently asked questions

Short answers about privacy, formats, Timeline, Lightroom and mobile use.

Is Clustr free?

Yes. Clustr is free and ad-free. There is no account, no subscription and no upload quota. Optional support through Ko-fi keeps development going.

Are my photos uploaded to a server?

No. Photos are read and processed in your browser. The app has no photo backend and never uploads your library. Metadata is stored locally in IndexedDB; photo blobs are not stored.

Does Clustr work with Google Timeline?

Yes. Import a Google Timeline JSON export and Clustr matches visits, activities and paths to your photo times. If Timeline is missing, GPS EXIF and interpolation are used instead.

Which photo formats are supported?

JPG, PNG, WebP, HEIC and HEIF, plus RAW formats such as NEF, CR2, ARW, DNG, ORF and RAF, and TIF or TIFF. Paired JPGs and embedded previews are used for RAW thumbnails.

Does Clustr work on a phone?

Yes, as a secondary workflow. Install the PWA, add photos from the camera roll, run the clustering phases and export a ZIP with photos and XMP sidecars. The primary workflow remains a PC with camera files.

Does Clustr work with Adobe Lightroom?

Yes. Export writes a folder hierarchy and XMP sidecars with keywords, hierarchical subjects, city and location fields that Lightroom can read.

Which browser do I need?

Use a Chromium-based browser on desktop for folder import and direct folder export. On mobile, any modern browser can install the PWA and export a ZIP.

Can Clustr run offline?

After the first load the service worker caches the app shell and vendor libraries, so Clustr works offline. Installing the PWA gives the most reliable storage behavior on iOS.

Ready to sort your camera library?

Open Clustr, select a folder and let the heatmap find the trips. Work from a copy of your photos and review the exported folders before deleting anything.
